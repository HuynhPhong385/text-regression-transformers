# Project Specification

## Description

Hệ thống Text Regression dự đoán sentiment score liên tục từ review.

## Goal

So sánh traditional ML và Transformer, đồng thời đánh giá frozen encoder vs fine-tuning.

## Scope

### In scope

- IMDb/Yelp;
- rating normalization;
- BERT;
- RoBERTa;
- DistilBERT;
- frozen/fine-tuning;
- metrics;
- API;
- UI;
- AI Agent workflow.

### Out of scope

- generative LLM;
- multilingual;
- distributed production training;
- online learning.

## Success criteria

- end-to-end training;
- reproducible experiments;
- checkpoint reload;
- model-level evaluation;
- full-pipeline test;
- final comparison;
- documented AI-assisted workflow.
