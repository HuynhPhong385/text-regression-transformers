# Implementation Prompt

Đọc plan và các Knowledge Base liên quan.

Implement smallest safe change.

Yêu cầu:
- tuân thủ naming convention;
- config-driven;
- không duplicate logic;
- type hints khi phù hợp;
- testable;
- không fake output.

Sau implementation:
1. chạy tests;
2. inspect diff;
3. cập nhật docs nếu behavior đổi;
4. cập nhật progress_status.md nếu task hoàn thành.
