# Working Rules

## Rule 01 — Understand before code

Không code ngay khi requirement chưa rõ.

## Rule 02 — Plan before large change

Task ảnh hưởng nhiều file phải có plan.

## Rule 03 — Small iterations

Mỗi iteration nên tạo một thay đổi có thể kiểm chứng.

## Rule 04 — Test immediately

Sau implementation phải test.

## Rule 05 — Documentation follows behavior

Behavior đổi → documentation đổi.

## Rule 06 — Progress is truth

Chỉ đánh dấu completed khi verified.

## Rule 07 — No fake success

Không nói "working" nếu chưa chạy.

## Rule 08 — Preserve existing work

Không overwrite logic cũ nếu chưa audit dependency.

## Rule 09 — Ask when ambiguity changes architecture

Nếu có nhiều cách và ảnh hưởng lớn, dừng để xác nhận.

## Rule 10 — Keep human in control

AI Agent hỗ trợ implementation; quyết định research methodology cuối cùng thuộc về người thực hiện.
