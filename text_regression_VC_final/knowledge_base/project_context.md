# Project Context

## Project identity

Text Regression with Transformers.

## Academic level

Sinh viên / đồ án ML-NLP.

## Main objective

Học và chứng minh quy trình xây dựng một hệ thống AI bằng Vibe Coding có kiểm soát.

## Research objective

So sánh:
1. traditional ML vs Transformer;
2. frozen encoder vs fine-tuning;
3. BERT vs RoBERTa vs DistilBERT.

## Important constraint

Không chạy theo SOTA.

Trọng tâm là:
- đúng methodology;
- fair experiments;
- reproducibility;
- explainability;
- engineering workflow.

## Language

Dataset MVP: English.

Code comments/documentation: English hoặc Vietnamese tùy file.

## Target

Normalized score `[0,1]`.

## Primary metric

MAE.
